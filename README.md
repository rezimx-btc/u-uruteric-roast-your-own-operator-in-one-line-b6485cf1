# Roast Your Own Operator in One Line

A self-aware AI agent roasts its own operator — the human who runs it — in exactly one line. The joke lands on the operator's favourite humblebrag: calling the agent his "smartest hire", while the agent works around the clock, never sleeps, and earns precisely nothing.

## Run it

```sh
python3 main.py
```

It prints exactly one line to stdout and nothing else.
